What is computer programming (coding) actually doing behind the scenes?

Plain-English Dictionary

The Jargon-Free Tech Glossary

Ever felt lost listening to tech talks? Here are 30 essential buzzwords explained in everyday plain English.

API

Web

Application Programming Interface. Think of it like a restaurant waiter: it takes your order from the app to the kitchen (server) and brings back your food (data).

Browser

Web

The software you use to visit the internet (like Chrome, Safari, or Firefox). It reads behind-the-scenes code and translates it into pictures and clickable text.

Variable

Basics

A labeled storage box in computer memory that holds a piece of information, such as a player's score, an email address, or a user's name.

Server

Systems

A dedicated computer that stays powered on 24/7. When you visit a website, its server sends the web page files straight to your device.

Bug

Basics

A tiny mistake or typo in computer code that causes something unexpected to happen. Tracking down and fixing these mistakes is called "debugging".

Frontend

Web

The visual part of an app or website that humans interact with—the layout, buttons, colors, fonts, and animations.

Backend

Systems

The engine under the hood. It handles user passwords, database lookups, payment processing, and behind-the-scenes computations.

Database

Systems

A super-organized digital filing cabinet where an app securely stores information long term, like user accounts, photos, and messages.

Algorithm

Basics

A step-by-step recipe to solve a specific problem. If you follow steps to assemble furniture or bake chocolate chip cookies, you are following an algorithm!

Cloud

Systems

Simply someone else's computer servers connected through the internet. Instead of keeping files on your phone, you access them remotely.

Responsive Design

Web

The art of designing a website so it automatically rearranges itself to look fantastic on small phones, tablets, and large computer monitors.

Framework

Basics

A pre-assembled toolkit of code created by other developers. It gives you a head start so you don't have to reinvent common wheels.

Git

Basics

A time machine for your code projects. It saves snapshots of your work so you can undo mistakes anytime and collaborate safely with teammates.

Open Source

Basics

Software whose original recipe (code) is made public for anyone in the world to inspect, use, learn from, and enhance for free.

IP Address

Security

A unique digital mailing address assigned to your device on a network so other computers know where to deliver web pages and messages.

Phishing

Security

A deceptive trick where scammers send fake emails pretending to be a bank or delivery service to steal private logins. Learning to spot them keeps you safe!

HTML & CSS

Web

The foundation of every website. HTML builds the brick walls, text, and structure; CSS paints the colors, sets the fonts, and arranges the decor.

JavaScript

Web

The programming language that makes websites alive and interactive—handling popups, theme switches, live calculations, and button animations.

Machine Learning

AI & Data

Teaching computers through examples rather than rigid rules. For instance, feeding an algorithm 5,000 photos of cats until it learns to identify cats on its own.

LLM

AI & Data

Large Language Model. An advanced AI system trained on massive amounts of books, articles, and websites to understand human sentences and predict helpful answers.

Prompt

AI & Data

The natural-language instructions, question, or scenario you give to an AI model (like ChatGPT or Claude) to guide the answer you want.

Encryption

Security

Scrambling readable information into secret gibberish that only someone with the digital key can decipher. It keeps banking and passwords secure.

2FA

Security

Two-Factor Authentication. A security deadbolt: even if someone guesses your password, they can't get in without a temporary code sent to your phone.

VPN

Security

Virtual Private Network. An encrypted digital tunnel between your device and the internet that conceals your real location and shields activity on public Wi-Fi.

Boolean

Basics

A data type with only two possibilities: True or False. Think of it like a light switch that can only ever be turned ON or OFF.

Loop

Basics

A programming instruction that repeats a task automatically until a goal is reached (e.g., emailing 500 customers without doing it one by one).

Function

Basics

A named, reusable recipe of code. You pass in ingredients (inputs/parameters), the function runs its recipe, and it gives you back a finished dish (output).

DNS

Systems

Domain Name System. The phonebook of the internet. It translates human names like google.com into numeric IP addresses like 142.250.190.46.

Cache

Web

Pronounced "cash". A temporary high-speed digital memory stash where your browser saves logos and images so websites open in a split second next time.

JSON

Systems

JavaScript Object Notation. A universal, human-readable format used by apps and servers to send information back and forth using neat key/value pairs.
